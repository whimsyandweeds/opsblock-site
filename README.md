# OPSBLOCK Site

Static landing page for OPSBLOCK modular business services.

## Live URL (after Pages is enabled)
https://whimsyandweeds.github.io/opsblock-site/

## Setup
1. Upload the `assets/` folder (contains images + video) to the root of this repo.
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / **(root)**
5. Save

Site will be live in 1–2 minutes.

## Files
- `index.html` — full single-page site (already here)
- `assets/` — images and hero video (upload this folder)
